# ASTRO VOID

A high-intensity retro vector space shooter inspired by classic Asteroids, built with React and HTML5 Canvas.

Fight through waves of asteroids and hostile UFOs, collect power-ups, and face multi-phase AI bosses in a neon TRON-style arena.

## Play

**Live demo:** [https://astro-void-game.netlify.app](https://astro-void-game.netlify.app)

## Features

- Classic Asteroids-style physics with modern upgrades
- Multiple enemy types and special asteroids
- Power-ups: Shield, Triple Shot, Laser, EMP, Time Warp, Drone, and more
- Multi-phase bosses (Wave 5, 10, 15...)
- Combo system and score multipliers
- CRT filter, screen shake, and synthesizer audio
- Local high scores and achievements
- Touch controls for mobile
- Multiple game modes (Classic, Survival, Zen)

## Controls

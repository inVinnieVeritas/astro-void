# ASTRO SMASH

A fast-paced neon vector arcade shooter inspired by classic Asteroids gameplay and TRON-style visuals.

Built with React, TypeScript and HTML5 Canvas, ASTRO SMASH combines arcade shooting, multiple game modes, boss encounters, achievements, challenges, power-ups and persistent statistics.

## Play the game

**Live version:**  
https://astro-void-game.netlify.app/

No installation or account is required to play.

## Features

- Classic arcade survival gameplay
- Multiple game modes:
  - Classic
  - Survival
  - Zen
  - Boss practice
- Desktop keyboard and mouse controls
- Touch and tablet controls
- Power-ups, shields, EMP attacks and hyperspace
- Combo and scoring systems
- Achievements and pilot challenges
- Lifetime gameplay statistics
- Local and global leaderboards
- Pause-aware gameplay systems
- Responsive HTML5 Canvas rendering

## Boss encounters

ASTRO SMASH includes three major boss battles:

### Wave 5: Dreadnought

A heavily armed warship protected by a rotating shield gap and periodic overheat vulnerability window.

### Wave 10: Core Severance

A central core protected by satellite nodes, energy tethers and a tracking beam system.

### Wave 15: Grid Architect

The final major encounter, featuring support drones, battlefield control mechanics and a sweeping lethal beam.

## Controls

The available controls depend on the selected control scheme and device.

The game supports:

- Keyboard
- Mouse
- Touchscreen
- Tablet controls

Full control instructions are available inside the game through the **How to Play** and settings interfaces.
